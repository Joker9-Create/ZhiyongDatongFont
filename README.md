## 安装使用
### Windows
右键 `ZhiyongDatongFont.ttf` → 安装

### macOS
双击 `ZhiyongDatongFont.ttf` → 安装字体

### 网页 / 前端 / 软件开发
支持 `@font-face` 网页嵌入、软件内嵌、客户端打包使用，无商用限制。
