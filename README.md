## 安装 / Installation

- Windows：右键点击 `ZhiyongDatongFont.ttf` → 安装
- macOS：双击 `ZhiyongDatongFont.ttf` → 点击「安装字体」
- 网页 / Web：使用 `@font-face` 引入该字体文件
